# Финальный экран запуска бизнеса

## Проблема

Текущий экран одновременно сообщает «Готово» и показывает неподключённый Telegram как незавершённый шаг. Из-за этого владелец не понимает, принимает ли бизнес записи. Блок «Ваша ссылка для записи» также не объясняет назначение ссылки и следующее действие.

## Решение

Финальный экран разделяет два независимых результата:

1. Базовый запуск страницы записи завершён.
2. Telegram — дополнительный канал, который можно подключить после запуска.

Верхний progress состоит из этапов «Услуга», «Оплата», «Запуск». На третьем этапе экран сообщает «Страница записи работает», а не обобщённое «Готово».

## Структура экрана

### Результат запуска

- Kicker: «Запись запущена».
- Заголовок: «Страница записи работает».
- Пояснение: клиенты уже могут выбирать услугу, специалиста и свободное время по публичной ссылке.
- Не показывать общий список из пяти пунктов, в котором обязательные и дополнительные действия выглядят одинаково.

### Ссылка для клиентов

- Заголовок: «Ссылка для клиентов».
- Пояснение: «Отправьте её клиентам или разместите в Instagram, Telegram и на сайте».
- Показывать короткий публичный путь бизнеса.
- Основное действие: «Открыть страницу».
- Вторичное действие: «Скопировать ссылку» с мгновенной обратной связью «Ссылка скопирована».
- Копирование использует абсолютный URL текущего сайта; открытие ведёт на существующий публичный маршрут `/b/{businessSlug}`.

### Дополнительный канал

- Отдельный спокойный блок без статуса ошибки.
- Если Telegram не подключён: заголовок «Добавьте запись через Telegram», краткое объяснение пользы и действие «Создать клиентского бота».
- Если Telegram подключён: компактный подтверждённый статус «Telegram подключён» и ссылка «Открыть интеграции».
- Неподключённый Telegram не отменяет результат базового запуска и не меняет статус верхнего progress.

## Удаляемые элементы

- Общий readiness-список с пятью строками.
- Противоречивые статусы «Готово» и «Перейти» внутри одного списка.
- Кнопки «Открыть кабинет» и «К каналам» на финальном экране.
- Формулировка «Ваша ссылка для записи» без объяснения назначения.

## Состояния и доступность

- Кнопка копирования работает как client component и объявляет результат через `aria-live`.
- При ошибке Clipboard API показывается конкретное сообщение и сама ссылка остаётся доступной для ручного копирования.
- Все интерактивные элементы сохраняют существующие hover, active и focus-visible состояния.
- На узком экране действия становятся вертикальными, без горизонтального переполнения.

## Границы задачи

- Не меняются условия готовности публичной страницы и серверная бизнес-логика.
- Telegram не становится обязательным шагом.
- Не меняются маршруты записи, интеграций и dashboard.
- Не добавляются аналитика, sharing API или QR-код.

## Проверка

- Component-тесты для неподключённого и подключённого Telegram.
- Component-тест состояния копирования и ошибки Clipboard API.
- E2E: после настройки услуги и оплаты заголовок сообщает о работающей странице; публичная ссылка открывается; Telegram отображается отдельным дополнительным каналом.
- Визуальная проверка desktop и mobile: ясная иерархия, отсутствие ложного незавершённого статуса и переполнения.
